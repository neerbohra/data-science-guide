Study Guide

NumPy Refresher

NumPy is the foundation for numerical computing in Python.

  • Core Object: ndarray (N-dimensional array).
  • Creation: np.array([1, 2, 3]) or np.zeros(5).
  • Sequences: np.arange(start, stop, step) for integer spacing, np.linspace(start, stop, num) for exact point counts.

Pandas Refresher

Pandas is built for tabular data manipulation.

  • Core Objects: Series (1D column) and DataFrame (2D table).
  • Selection: df.loc[] selects by explicit label, df.iloc[] selects by integer position.
  • Filtering: df[df['Age'] > 20] uses boolean masking.

Matplotlib

The low-level foundation, mimicking MATLAB's plotting style.

  • Core Submodule: matplotlib.pyplot (imported as plt).
  • Basic Plotting: plt.plot(x, y) for lines/markers, plt.scatter(x, y) for dots.
  • Structure: You build plots step-by-step. plt.title(), plt.xlabel(), and finally plt.show() to display.
  • Subplots: plt.subplot(rows, cols, index) layers multiple charts.

Seaborn

High-level statistical storytelling built on top of Matplotlib.

  • Categorical Plots: sns.catplot() handles box, violin, strip, and bar plots across grids automatically.
  • Distributions: sns.kdeplot() applies Kernel Density Estimation for smooth curves; sns.histplot() for bins.
  • Relational & Matrices: sns.scatterplot() for points, sns.heatmap() for correlation matrices.

Plotly (Plotly Express)

Interactive web-based visualizations.

  • Interface: Plotly Express (px) allows you to build complex interactive charts in one line.
  • Features: Built-in zooming, panning, and hover-data (e.g., px.scatter(df, x='Age', y='Fare', color='Survived')).
  • Exporting: Saves to interactive HTML using fig.write_html().
