1.1 Defining, Calling, Docstrings, & Parameters vs. Arguments

  • Parameter vs. Argument: A parameter is the variable placeholder in the function definition (def greet(name):). An argument is the actual value passed at call time (greet("Emil")).
  • Object vs. Call: Writing my_function without parentheses references the function object; my_function() executes it.
  • Default Parameters: Parameters with defaults (e.g., country="Norway") must come after parameters without defaults. Never use mutable objects (like []) as default values; use None instead.

def area(w: float, h: float = 1.0) -> float: """Return the area of a rectangle.""" return w * h print(area.__doc__) # Access docstring print(area(5, 3)) # Positional arguments print(area(5)) # Uses default h=1.0 print(area(h=4, w=2)) # Keyword arguments (order doesn't matter) def work_in_progress(): pass # Avoids IndentationError for empty body

1.2 *args, **kwargs, Call Unpacking, & The Argument Order Rule

Syntax Data Structure Created When to Use Opposite Operation (At Call Time)
*args (in def) Tuple (val1, val2, ...) Unknown number of positional arguments. Access by index (args[0]). func(*my_list) unpacks a list/tuple into separate positional arguments.
**kwargs (in def) Dictionary {'k': v} Unknown number of keyword arguments. Access by key (kwargs['lname']). func(**my_dict) unpacks a dict into separate key=value arguments.
Strict Python Argument Order Rule: When combining parameter types in one function definition, Python requires this exact sequence:
$\text{positional} \rightarrow \texttt{*args} \rightarrow \text{keyword-only (after *args)} \rightarrow \texttt{**kwargs}$

Feature print(value) return value
Effect Displays text on the screen for humans; function hands back None. Exits the function immediately and hands the value back to the caller so it can be saved in a variable or used in math.

2A.1 Array Creation, Inspection Properties, & arange vs. linspace

Function Syntax Mathematical Behavior Best Use Case
np.arange() np.arange(start, stop, step) Generates values on half-open interval $[\text{start}, \text{stop})$ separated by fixed step $s$. Integer sequences or index grids (e.g., np.arange(0, 10, 2) $\rightarrow$ [0, 2, 4, 6, 8]).

2A.2 Matrix Indexing, Transpose ($A^T$), Element-Wise ($*$) vs. Matrix Product ($@$)

Matrix Dimension & Transpose Rules:
• Matrix Multiplication (A @ B): If $A$ has shape $(m \times n)$ and $B$ has shape $(n \times p)$, then $C = A @ B$ has shape $(m \times p)$ with entries $C_{ij} = \sum_{k=1}^{n} A_{ik} B_{kj}$. By contrast, A * B multiplies element-by-element ($A_{ij} \cdot B_{ij}$).
• Transpose (A.T): Exchanges rows and columns so $(A^T)_{ij} = A_{ji}$. If $A$ is $(2 \times 3)$, then $A^T$ is $(3 \times 2)$.

Deck 3: Python Matplotlib (pyplot)

Complete syntax from Dr. Abebe's Python Matplotlib deck: line & marker formatting, fontdicts, grid customization, plt.subplot(), colormaps (cmap), bars, histograms, and pie charts.

How Matplotlib Compares to Seaborn & Plotly
  • Matplotlib (plt) vs. Seaborn (sns): Matplotlib is low-level and manual—you pass separate $x$ and $y$ arrays and build titles, grids, and subplots line by line. Seaborn sits on top of Matplotlib to automate statistical aggregations and multi-panel facets from a DataFrame.
  • Why you still need Matplotlib: Even when plotting with Seaborn, you call plt.title(), plt.xlabel(), plt.savefig("fig.jpg"), and plt.show() to label, save, and render the figure.

3.1 Markers, Lines, Format Strings ('o:r'), FontDicts, & Grids

  • Default $X$-Points: Calling plt.plot(ypoints) with only one array automatically sets $x = [0, 1, 2, \dots, n-1]$.
  • Format String Shortcut: 'o:r' combines marker='o' + linestyle=':' (dotted) + color='r' (red).
  • Marker Keyword Styling: ms = marker size, mec = marker edge color, mfc = marker face (fill) color.
  • Line Keyword Styling: ls ('-' solid, ':' dotted, '--' dashed, '-.' dashdot), c (color), lw (linewidth).
matplotlib_lines_markers_labels.py
import matplotlib.pyplot as plt import numpy as np x = np.array([80, 90, 100, 110, 120]) y = np.array([240, 260, 280, 300, 320]) font1 = {'family': 'serif', 'color': 'blue', 'size': 16} font2 = {'family': 'serif', 'color': 'darkred', 'size': 12} plt.plot(x, y, marker='o', ms=10, mec='#4CAF50', mfc='#4CAF50', ls='--', lw=2) plt.title("Sports Watch Data", fontdict=font1, loc='left') plt.xlabel("Average Pulse", fontdict=font2) plt.ylabel("Calorie Burnage", fontdict=font2) plt.grid(axis='both', color='green', linestyle='--', linewidth=0.5) plt.show()
