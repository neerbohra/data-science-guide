Python Functions & Lambda

Reusable code blocks, *args/**kwargs unpacking, and one-line anonymous functions.

functions_demo.py
1# Function with default parameter & multiple returns
2def min_max(numbers, scale=1):
3    return min(numbers) * scale, max(numbers) * scale
4
5low, high = min_max([4, 9, 1, 7], scale=10)
6print(f"Low: {low}, High: {high}")
7
8# Lambda (anonymous) function
9square = lambda x: x ** 2
10print("5 squared:", square(5))

Low: 10, High: 90 5 squared: 25
